GGJ 2026: Hosted by Unity Montreal, a few friends and I participated in this year’s “mask” global game jam. 
Tetris-style blocks are used to protect phil the turtle from the coloured masks. 
It uses the color wheel, where blocks kill the masks only when they are complementary to each other. 
Fun concept! I helped model and design.

## Stuff I worked on:

- Modeling the turtle and the masks
- Modeling the blocks
- Textured
- Designing the levels
