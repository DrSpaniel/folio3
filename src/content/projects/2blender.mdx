I've found blender to be a point of fascination for me since about 2019. 
It wasn't until 2021 that I began my journey by following [Blender Guru](https://www.youtube.com/@blenderguru)'s
famous donut tutorial. Later I also jumped into learning first person animation.
To be honest, it's not the best. But I am still working on new animations today
## Features

- 100 / 100 Lighthouse performance
- Responsive for all screen sizes
- Fully accessible
- Type-Safe
- Auto-generated sitemap
- Markdown / MDX Support
- Builds on content collections
- Search powered by [pagefind](https://pagefind.app)
- Comments powered by [giscus](https://giscus.app) (can be turned off)
- More!

## Speedy

Spectre uses no additional frameworks, not even Tailwind. This results in incredibly fast load and build times.

Spectre's unique features can all be turned on or off and even modified. If you, for example, dislike the comments, you can disable them with ease.
